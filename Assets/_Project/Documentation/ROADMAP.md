# ROADMAP

Фазы перечислены для планирования. **Ничего из этого не реализовано в Фазе 1.**

## Фаза 1 — планета, полёт, космос (текущая)
Гравитация в СИ, Velocity Verlet с фиксированным шагом, атмосфера и сопротивление, непрерывный переход в космос,
floating origin, процедурная поверхность с LOD и сохранением, HUD, Flight Manual, тесты.

## Фаза 1.1 — доводка по результатам проверки в редакторе
- Прогнать тесты Unity Test Runner, профилировать (Mono vs IL2CPP), подобрать бюджеты LOD и число выборок атмосферы.
- Тонмаппинг/экспозиция через URP Volume вместо простого `1 − e^(−x)` в шейдере; авто-экспозиция при выходе из атмосферы.
- Спектральная прозрачность для далёкой сцены (dual-source blending или полноэкранный проход Renderer Feature).
- Предрасчитанные LUT пропускания/рассеяния (Bruneton) вместо ray-marching — быстрее и с многократным рассеянием.
- UI Toolkit вместо IMGUI.

## Фаза 2 — аппарат и двигатель
- Тяга, I_sp, массовый расход, переменная масса (формулы — PHYSICS.md §9).
- Ориентация аппарата: момент инерции, гироскопы/RCS, интегрирование вращения (кватернионы).
- Полноценная аэродинамика: Cd(M, Re), подъёмная сила, центр давления, нагрев, ограничения q и перегрузки.
- Потери на гравитацию и сопротивление в телеметрии.

## Фаза 3 — инструменты планирования (Mission Planning)
- Прогноз траектории (численный, с атмосферой) и узлы манёвров, которые игрок задаёт сам; калькулятор Δv по Циолковскому.
- Гомановский перелёт, плоскость орбиты, окна запуска — как справочник и проверка расчётов игрока, а не автопилот.
- Сохранение полной сессии (состояние аппарата, время, изменения поверхности).

## Фаза 4 — Солнечная система
- Эфемериды (кеплеровы элементы или JPL), гелиоцентрическая инерциальная система, сферы влияния/N-тел.
- Луны и кольца, приливное запирание, сжатие планет (J2).
- Облака (параметр `cloudCoverage` уже хранится), океан с волнами, ночные огни, эрозия и тектоника в генераторе (алгоритм v2).
- Табличные атмосферы для Марса/Венеры/Титана, состав и температурный профиль.

## Фаза 5 — другие звёздные системы
- Процедурные системы: звезда (класс, светимость, цвет), орбиты планет; физика планет — через `PlanetPhysicalGenerator` с сохранением.
- Межзвёздные масштабы: иерархия систем отсчёта (галактика → система → планета) поверх текущего floating origin.
